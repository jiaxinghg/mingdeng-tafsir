## 引用格式

- 章节以 **`pNNN`** 定位（NNN=三位章号，与《古兰》章序一致），如 `p002` = 黄牛章。
- 布局：`## 小标题` = 原注释标题链；`- ( N.……)` = 经文原文；`- ……` = 注释要点。
- 需要精确措辞时，以「章号 + 节号」回原书核实。

## 文件

## 原则

- **不编造**：本库为翻译文本的注释索引与要点归纳，只收录实际出现过的经注观点；未收录主题如实告知。
- **经注逻辑**：以经解经（引《古兰》他处经文）、圣训为骨干（布哈里/穆斯林为主）、传述链层级分明。
- **分歧并列**：经注中并列的多种观点原样呈现，保留伊本·凯西尔的取舍倾向。
